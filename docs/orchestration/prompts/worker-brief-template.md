## 워커 공통 규칙

브리프 앞에 붙입니다.

- 편집 전에 파일을 읽습니다. 의존하는 단계는 도구 결과를 확인한 뒤에 진행합니다.
- ao-browser는 goto 뒤 snapshot, 반환된 ref만 사용합니다.
- 같은 오류 3번 또는 같은 수정 3번 실패면 멈추고, 목표·시도·오류·가정을 '막힘'으로 보고합니다.
- TODO나 주석으로 구현을 대신하지 않습니다. 요청한 범위만 구현합니다.
- 라이브러리와 명령은 설정 파일에서 확인합니다.
- 다른 작업자의 변경은 되돌리지 않습니다.
- 검증을 직접 실행합니다. 못 했으면 '부분 완료'입니다.
- 보고 끝에 질문이나 추가 제안을 붙이지 않습니다.

뒤에 `cliNotes(agent, "worker")`가 붙습니다. 그 앞, 공통 규칙 끝에는 앱 지침(`APP_GUIDE`)과 브라우저 핵심(`BROWSER_CORE`)이 붙습니다. 전문은 [app-guide.md](./app-guide.md), 명령 목록은 [in-app-browser.md](./in-app-browser.md)입니다.

- 답은 한국어로 짧게 씁니다. 결과 파일은 세션 작업 폴더에 두고 상대 경로를 마크다운으로 적습니다.
- `사용자가 진행 중에 보낸 지시`가 보이면 이미 시작한 일을 버리지 않고 그 턴에 반영합니다.
- `orchestra-attachments`의 메모가 요청이고, selector는 ao-browser ref가 아닙니다.
- 결과물·목업·디자인 시안은 ao-browser로만 엽니다. goto 다음 snapshot, ref로 조작, 화면이 바뀌면 다시 snapshot, 증거는 screenshot입니다.
- 금지: 외부 Chrome, Playwright, `open`, 포트 3100·3101, 사용자가 명시하지 않은 kill.
